#PRD: Discipline

## Summary:
Personal development webapp where you can:
- Track Habits
- Set recurring and non recurring tasks with different priorities
- Analyze data from the previous two points

## Problem: 
I find myself using multiple tools trying to solve my needs and realize that:
- No app is able to solve all my needs
- No app solves each need as I wish

## Users:
Myself. I will be the main user, this app is designed for me. 

Will be using it from my PC and phone

## Goals:
Make myself independent. Personalize my needs. 

## Non-Goals:
- Any AI bullshit

## Out of Scope (For the moment):
- Calendar integration
- Account / User log in

## User Stories:
- As a user, I want to create daily habits
- As a user, I want to create non-daily habits (Repeating on Monday, Wendsday and Friday)
- As a user, I want to marck my habits as completed
- As a user, I want to delete habits
- As a user, I want to edit habits
- As a user, I want to add an icon to a habit
- As a user, I want to create tasks
- As a user, I want to set ONE MUST ACCOMPLISH task for the day
- As a user, I want to set THREE SHOULD ACCOMPLISH tasks for the day
- As a user, I want to have a bag/backburner of tasks 
- As a user, I want to analyze:
  - How many habits have I accomplished on the past days (Calendar view)
  - How many days in a row I have completed a specific habit
  - What days I have (not) completed a specific habit

## Success Metrics:
When I like it
